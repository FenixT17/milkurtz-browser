# Assets

Pasta de recursos visuais do Milkurtz Browser.

- `Milkurtz.ico` — ícone do navegador e do instalador (necessário para o build).
- `logo-milkurtz-browser.jpg` — logo de divulgação.

> Nota: como o projeto foi reconstruído, os arquivos de imagem precisam ser
> regenerados ou restaurados. Um `Milkurtz.ico` simples pode ser criado com
> qualquer ferramenta de conversão de imagem (por exemplo: png2ico).
